# irps 0.1.0 (2026-05-09)

* Initial CRAN release.
* Core `compute_irps()` function for Immune Response Potential Score computation.
* `decompose_portrait()` for 7-dimension immune microenvironment portrait.
* `classify_phenotype()` for Immune-Inflamed / Excluded / Desert classification.
* `validate_hallmark()` for MSigDB Hallmark external validation.
* `get_immune_gene_sets()` returns the 18 built-in curated immune gene sets.
* `map_genes_to_features()` utility for mapping gene symbols to expression feature IDs.
* Comprehensive visualization suite: boxplot, heatmap, radar chart, portrait panel, phenotype bar, scatter plot.
* S3 methods: `print.irps()`, `summary.irps()`, `plot.irps()`.
* Vignette with full usage examples.
